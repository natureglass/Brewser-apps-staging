USB devices on the port

Opens the picker for every attached USB device (empty filter) and dumps its descriptor. If your ESP32 doesn't appear here, it isn't enumerating as a USB device at all — use the board's native USB port and build with USB CDC On Boot: Enabled. A CDC-ACM interface shows class 0x02/0x02 (+ a 0x0a data iface).

Bluetooth LE

The Switch scanner is filter-based: enter an advertised service UUID (16-bit alias like 0x180D, or a full 128-bit UUID). Nordic UART is pre-filled. Scans ~8 s then shows the chooser.
