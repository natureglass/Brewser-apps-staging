Phaser compatibility demos for Brewser

Run the same demo across the four variants. Phaser 3 Canvas is the control: if it works there and not in WebGL, the bug is in the GL bridge; if it fails in both, it is canvas 2D, DOM, loader or JS.

Overlay top-left shows Phaser version, requested vs actual renderer, GL version string, rAF fps, and any error/warning. Green = clean, red = something threw.

  1. 01 Platformer baseline
    Arcade physics, spritesheet anims, Gamepad API
    Phaser 3.90 / WebGL  |  Phaser 3.90 / Canvas  |  Phaser 4.2.1 / WebGL  |  Phaser 4.2.1 / Canvas
  2. 02 Text vs BitmapText
    canvas-rasterised Text (measureText/fillText -> texture upload) vs atlas BitmapText control
    Phaser 3.90 / WebGL  |  Phaser 3.90 / Canvas  |  Phaser 4.2.1 / WebGL  |  Phaser 4.2.1 / Canvas
  3. 03 Particles
    sprite batch throughput, ADD vs NORMAL blend, tint
    Phaser 3.90 / WebGL  |  Phaser 3.90 / Canvas  |  Phaser 4.2.1 / WebGL  |  Phaser 4.2.1 / Canvas
  4. 04 Tilemap
    JSON via XHR, tilemap layer renderer, camera scroll, tile collision
    Phaser 3.90 / WebGL  |  Phaser 3.90 / Canvas  |  Phaser 4.2.1 / WebGL  |  Phaser 4.2.1 / Canvas
  5. 05 FX + Shader + Graphics
